Quedan tres listeners de marvel:state-synced:

- apply() del motor TMDB/media.
- propietario canónico V1.10.15 que coordina los renders del estado.

La presencia de los tres es intencionada: los dos primeros son módulos especializados y no simples renders generales.

6. ARCHIVO ELIMINADO

core/marvel-core-v1.10.js

No se referencia en index.html ni en netlify.toml. El runtime actual carga el core mediante el loader inline. El archivo se considera un artefacto de una etapa histórica y se retira del deploy actual; la documentación histórica no se modifica.

7. COSAS DELIBERADAMENTE NO ELIMINADAS

MarvelProfileManager se mantiene porque representa una API pública/compatibilidad potencial aunque la UI actual use funciones V111 específicas.

Los módulos V115/v102 que aún contienen APIs utilizadas no se eliminan enteros; solo se retiran sus listeners demostrablemente redundantes.

TMDB, posters, ficha, Cloud, Service Worker, observers y estilos no se modifican.
