V1.18.1 · TEST REPORT · CORRECCIÓN CONFIRMACIÓN CLOUD

1. Hallazgo reproducible por lectura del flujo
- V1.18 llamaba a window.__marvelProfileSave() desde «Crear copia ahora».
- El coordinador conservador de guardado (V1.10.10/V1.16) devuelve un objeto {ok:true, cloud:true} cuando Cloud se confirma, no necesariamente el booleano true.
- V1.18 comparaba estrictamente saved !== true.
- Resultado: un guardado Cloud correcto podía continuar internamente pero la interfaz rechazaba la creación de la copia con el mensaje «Primero debe quedar confirmado el guardado Cloud actual».

2. Corrección aplicada
- Se acepta saved === true o saved.cloud === true como confirmación Cloud.
- Se aplica la misma corrección al flujo de restauración Cloud.
- Cuando no hay confirmación, se muestra el error disponible en el resultado si existe.
