BUILD
- NODE_VERSION=22 se mantiene en netlify.toml.
- No crear una variable NODE_VERSION adicional en la UI.
- Build command: npm install --omit=dev.
- Dependency: @netlify/blobs 10.7.13.

STORAGE
V1.18 introduce un Blob Store dedicado para copias:
marvel-marathon-backups-v1

No requiere configurar una nueva variable. La Function usa la misma autenticación y sesión server-side existente y crea/consulta los blobs desde Netlify.
